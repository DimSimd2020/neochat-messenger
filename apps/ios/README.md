# NeoChat для iOS

Клиент на Swift и UIKit, iOS 15 и новее. Шифрование, хранилище и синхронизация находятся в общем Rust-ядре (`core/`). Ядро статически линкуется как `libneocore.a`.

- Ключ базы SQLCipher хранится в Keychain (`AfterFirstUnlockThisDeviceOnly`).
- Интерфейс только на русском: `CFBundleDevelopmentRegion` и `CFBundleLocalizations` = `ru`, поэтому системные кнопки («Закрыть», «Отменить») тоже показываются по-русски.
- Привязка нового устройства: «Устройства → Сканировать QR-код» (AVFoundation). Если камеры нет, код можно вставить вручную.
- Уведомления показывают только название чата.
- В 0.6.2: собственный непрозрачный фон переписки и отключение неявных переходов фоновых слоёв для устранения наложения текста; анимированный статус набора; смена фото профиля; выбор чатов и массовые действия; локальная очистка; компактный архив по потягиванию списка вниз. Фото профиля требует обновления сервера с миграцией `0006_avatar.sql`.

## Сборка

Собирается в GitHub Actions на macOS (`.github/workflows/ios.yml`) как неподписанная IPA для установки через Scarlet. Локально на Mac:

```bash
rustup target add aarch64-apple-ios
cd core && cargo build --release --lib --target aarch64-apple-ios && cd ..
cd apps/ios && xcodegen generate
xcodebuild -project NeoChat.xcodeproj -scheme NeoChat -configuration Release -sdk iphoneos \
  -derivedDataPath build CODE_SIGNING_ALLOWED=NO build
```

Для ветки с изменениями достаточно отправить коммиты и запустить workflow:

```bash
git push
gh workflow run ios.yml --ref <branch>
gh run list --workflow ios.yml --branch <branch>
gh run download RUN_ID --name NeoChat-unsigned-ipa --dir "$TEMP/neochat-ipa"
cp "$TEMP/neochat-ipa/NeoChat-unsigned.ipa" dist/NeoChat-<версия>-ios-unsigned.ipa
```

Ручной запуск сохраняет IPA только в артефакт `NeoChat-unsigned-ipa` и не публикует GitHub Release. Проверки ядра на host и UI-тест на симуляторе включаются опцией `run_tests=true`; по умолчанию выключены. При их запуске `ios-simulator-shots` содержит снимки теста.

## Проверка

CI проверяет, что сборка проходит и ядро слинковано статически (`otool -L` не находит `neocore`). На реальном устройстве нужно пройти вход, переписку, вход компьютера по QR и сверку кода безопасности.

UI-тест также проверяет ответ свайпом влево по пузырю и по пустой части строки, открытие меню нажатием, выбор «Ответить» и отмену ответа. Быструю реакцию двойным касанием тест не проверяет: без сервера сообщение остаётся неотправленным, а на него реакцию поставить нельзя. После действий приложение должно оставаться открытым в том же чате. Этот сценарий нужно повторить на физическом iPhone: успешный тест симулятора сам по себе не подтверждает устранение вылета на устройстве.

### Архив, текстовые вкладки и своя камера (рабочая копия, 22.10.2026)

Вытягиванием архива управляет отдельный жест: он не конкурирует с пружиной прокрутки и крупным заголовком навигации. Высота строки имеет один прерываемый переход; круг прогресса не использует неявную анимацию Core Animation и завершается при полном раскрытии. Фильтры чатов и вкладки профиля используют линзу нижней навигации, с нативными кнопками для VoiceOver и клавиатуры. Добавлены значки групп и голубое выделение выбранных строк.

Превью своей камеры подключено напрямую к `AVCaptureSession` через `AVCaptureVideoPreviewLayer`. Фронтальное изображение зеркальное; при повторном открытии экрана звонка превью подключается к текущей сессии. Состояние «камера включена» устанавливается после успешного завершения запуска захвата. Выключение камеры или завершение звонка во время запуска отменяет применение его результата; повторное переключение камер блокируется до завершения предыдущего.

UI-тест дополнен выбором фильтров и вкладок профиля, коротким вытягиванием архива и проверкой открытия после отпускания. **Эти изменения iOS пока не собраны и не запущены:** работа выполнена на Windows без Xcode. На iPhone требуется проверить частичный и полный жесты, быстрый повтор и отмену, открытие архива, прокрутку и возврат; во входящем и исходящем видеозвонках — своё превью, смену камер, выключение во время запуска, сворачивание экрана звонка и возврат. Результаты Android не подтверждают поведение камеры или плавность на iOS.

### Шапка переписки по структуре Android (рабочая копия, 23.10.2026)

Вместо отдельной капсулы с именем и разрозненных кнопок навигации используется общая стеклянная панель: «Назад», аватар 40 pt, имя и статус с выравниванием влево, отдельные аудио- и видеозвонки, меню. Кнопки звонков появляются только в доступной личной переписке. Сведения открываются нажатием на аватар/имя или через меню; там же осталось действие очистки чата. Поиск внутри переписки в iOS пока не реализован, кнопка поиска не добавлена.

Высота панели начинается с 60 pt и растёт с Dynamic Type; длинные имя и статус обрезаются в одну строку. Области кнопок — 44 pt. Панель учитывает safe area, системный свайп назад остаётся в `ChatNavController`. Системная навигационная панель скрывается в переписке и возвращается на остальных экранах. Отклик кнопок использует существующие пружины и настройку уменьшения движения.

UI-сценарий дополнен проверкой расположения и доступности кнопок, отсутствия звонков в канале, открытия сведений обоими способами и возврата кнопкой; прежние проверки свайпа назад и меню очистки сохранены. **Сборка и UI-тесты этих изменений не запускались:** на текущем Windows-компьютере нет Xcode. Нужны сборка на macOS и проверка на iPhone: длинное имя, увеличенный текст, обе темы, поворот экрана, личный чат с двумя кнопками звонков, переход в профиль и возврат, завершённый и отменённый свайп назад с открытой клавиатурой.

## Ограничения

IPA 0.6.3 (build 13, arm64, iOS 15+) собрана в [GitHub Actions](https://github.com/DimSimd2020/neochat-messenger/actions/runs/39518149691), коммит `dc291f9`. Сборка IPA и UI-тест на симуляторе прошли; архив и версия артефакта проверены после загрузки. Проверка на физическом iPhone остаётся отдельным шагом; сценарии перечислены в [заметках 0.6.3](../../docs/13-release-0.6.3.md).

- Мгновенных push-уведомлений нет: для APNs нужна подпись разработчика. Новые сообщения приходят, пока приложение открыто, или при фоновом обновлении (`BGAppRefreshTask`).
- В 0.6.3: ответ свайпом влево по всей ширине строки, быстрая реакция двойным касанием (выбирается в настройках, общая для всех устройств), окно «Что нового» после обновления. Контакты, закрепы, архив и быстрая реакция синхронизируются между своими устройствами через ядро.
- Звонки (0.6.3) один на один, WebRTC из пакета `stasel/WebRTC` 152.0.0 (SPM).
  - Входящий звонок звонит только при открытом приложении: без PushKit/CallKit и подписи разработчика iOS не будит приложение ради звонка. Если приложение ушло в фон незадолго до звонка, приходит уведомление «Входящий звонок».
  - Идущий звонок продолжается в фоне (`UIBackgroundModes: audio`).
  - Устройства ввода и вывода выбирает система; переключатель «Динамик» направляет звук на громкоговоритель.
