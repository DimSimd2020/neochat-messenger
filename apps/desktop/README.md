# NeoChat Desktop (Windows, Qt/C++)

Нативный клиент на Qt 6 Widgets. Шифрование, хранилище и синхронизацию выполняет общее Rust-ядро [`core/`](../../core) (libsignal, SQLCipher), которое статически линкуется в приложение через C ABI ([`neocore.h`](../../core/include/neocore.h)). WebView нет.

## Что реализовано

- Вход и первый запуск:
  - регистрация без приглашений;
  - обязательное подтверждение сохранения recovery code;
  - вход по паролю на новом компьютере: ключи и переписка восстанавливаются из копии на сервере, зашифрованной паролем;
  - рядом с формой входа — QR-код: телефон сканирует его и впускает компьютер;
  - код подтверждения входа (если включён в настройках) приходит в чат «NeoChat уведомления»;
  - восстановление по коду;
  - повторный вход по паролю, когда сессия истекла.
- Список чатов:
  - поиск, фильтры «Все / Личные / Группы»;
  - непрочитанные, черновики, предупреждение о смене ключа.
- Переписка:
  - группировка сообщений, даты;
  - статусы «В очереди → На сервере → Доставлено → Прочитано», для групп — число доставленных;
  - «Повторить» при ошибке;
  - ответ, копирование, удаление у себя;
  - файлы до 25 МиБ: зашифрованная загрузка, расшифровка во временный файл только по действию пользователя, «Сохранить как…»;
  - поиск по локальной истории.
- Композер:
  - стрелка отправки появляется за 240 мс, эмодзи сдвигается на 51 px;
  - скрытая кнопка не входит в Tab-порядок;
  - Enter или Ctrl+Enter — по настройке;
  - выбор эмодзи, перетаскивание файлов;
  - при смене ключа отправка заблокирована.
- Контакты: точный поиск по username, имя и фамилия, сортировка.
- Группы до 16 участников:
  - создание;
  - переименование, добавление и исключение участников владельцем;
  - выход.
- Сведения о беседе:
  - код безопасности (12 групп по 5 цифр);
  - отметка о сверке;
  - принятие нового ключа после сверки.
- Устройства: список и отзыв с любого устройства аккаунта.
- Системный чат «NeoChat уведомления»: коды входа и сообщения о новых устройствах, писать в него нельзя.
- Настройки:
  - ползунок темы «устройство → день → ночь» (220 мс), смена палитры за 420 мс;
  - размер текста, отчёты о прочтении, уведомления, выход.
- Окна закрываются по Escape, крестику и настоящему клику снаружи; фокус удерживается внутри и возвращается к открывшему контролу.
- Скрытие списка за 240 мс, Ctrl+K, однопанельный режим при ширине 760 px и меньше.
- Reduced motion: если в Windows выключено «Показывать анимацию», все переходы мгновенные. Настройка читается на лету.
- Ключ локальной базы — случайные 32 байта, хранятся только в виде DPAPI (привязаны к пользователю Windows).
- Одновременно запускается одна копия приложения.

Уведомления Windows показывают только название беседы и «Новое сообщение», без текста.

## Сборка

Нужны:
- Visual Studio 2022 с C++;
- Qt 6.8 (msvc2022_64);
- Rust stable;
- Strawberry Perl (для OpenSSL внутри SQLCipher);
- protoc;
- cmake и ninja.

Пути по умолчанию заданы в `build.cmd`, их можно переопределить переменными `QT_DIR`, `PERL`, `PROTOC`.

```bat
apps\desktop\build.cmd
```

Скрипт вызывает `cargo build --release --lib` для ядра и собирает `apps\desktop\build\neochat.exe`. Поддерживается только Release: ядро собрано с release CRT.

Запуск из каталога сборки (Qt должен быть в `PATH`):

```bat
set PATH=E:\dev\Qt\6.8.3\bin;%PATH%
apps\desktop\build\neochat.exe
```

Сервер по умолчанию — `https://r1270286.s2566.vm.mydomain.zone:8443`. На экране входа его можно изменить.

## Установщик

```bat
apps\desktop\packaging\package.cmd
```

Скрипт делает следующее:
1. Собирает `build\stage`: `windeployqt`, локальный VC runtime и `LICENSE.txt`.
2. Из этого каталога собирает `build\NeoChat-0.1.0-x64.msi` через WiX v6.

Установка выполняется на пользователя, без прав администратора, в `%LOCALAPPDATA%\Programs\NeoChat`. Ярлык создаётся в меню «Пуск». Данные приложения лежат в `%LOCALAPPDATA%\NeoChat\NeoChat`. Подписи кода нет: Windows SmartScreen предупредит при первом запуске.

Проверка состава пакета без установки:

```powershell
msiexec /a apps\desktop\build\NeoChat-0.1.0-x64.msi /qn TARGETDIR=C:\temp\neochat-msi
```

## Проверки

UI-сценарий проходит по настоящим виджетам в режиме offscreen против локального Go-сервера. Второй участник — headless-клиент на том же ядре. Шаги сценария:
1. Регистрация и подтверждение recovery code.
2. Добавление контакта, входящее сообщение.
3. Набор и отправка; появление стрелки отправки.
4. Файл, который собеседник расшифровывает побайтно.
5. Отчёт о прочтении, группа.
6. Тема и Escape, скрытие списка.
7. Смена ключа собеседника: отправка заблокирована, показан код безопасности.

Нужен PostgreSQL и собранный `neochat_uitest.exe` (собирается тем же `build.cmd`).

```bash
NEOCHAT_E2E_DATABASE_URL="postgres://postgres@127.0.0.1:55432/neochat_e2e" ./scripts/uitest.sh
```

Снимки шагов сохраняются в `apps/desktop/build/shots` (или в `NEOCHAT_SHOTS`). Последний прогон: 8 из 8 сценариев, Windows 11, Qt 6.8.3, MSVC 19.44.

## Ограничения

- Только Windows x64. Сборки для macOS и Linux не делались.
- Сканирования QR камерой на компьютере нет: компьютер только показывает QR-код, сканирует его телефон.
- Размытие и стекло веб-эскиза не переносились: Qt-клиент следует исходной Qt-компоновке из [описания интерфейса](../../docs/05-interface.md).
- Масштаб 0.975 → 1 при появлении окон не используется: остаются затухание и сдвиг 10 px. Изменение геометрии во время анимации давало бы дёргание содержимого.
- Звонков нет.
