# NeoChat 0.6.1

Изменения от 20 октября 2026 года.

- iOS: свайп назад разрешён только при наличии предыдущего экрана и вне другого перехода; клавиатура закрывается при уходе из чата. Галочки доставки рисуются теми же линиями, что на Android, с соответствующими цветами и прозрачностью.
- Windows: выделение текста мышью и копирование по Ctrl+C; выбор нескольких сообщений для копирования, пересылки и удаления.
- На всех трёх платформах действия сообщения доступны по всей ширине его строки. Фото, ссылки, опросы и реакции сохраняют отдельные действия.
- Удаление своих сообщений у всех через зашифрованную команду. Локальное удаление и запись команды в очередь атомарны. Клиент отклоняет удаление чужих сообщений и запоминает удалённые, чтобы задержанная доставка не вернула их в историю. Открытая переписка обновляется и при удалении последнего сообщения.
- Пересылка текста, файлов и опросов с заголовком автора. Файл нужно предварительно скачать; он загружается отдельным зашифрованным вложением с правами целевой беседы. При пересылке проверяются права на отправку файлов и опросов.
- Реакции получают короткое появление при изменении; системное уменьшение движения учитывается. Используются системные эмодзи.
- Зашифрованная резервная история сохраняет заголовки пересылки и сведения об удалении у всех.

Для обработки удаления у всех получателю нужен клиент 0.6.1 или новее. Удаление не может отозвать уже сохранённую собеседником копию или снимок экрана. IPA остаётся неподписанной для установки через Scarlet; физический iPhone требует отдельной проверки.

Сборки и проверки выпуска фиксируются в описании GitHub Release. Общий запуск E2E с одним сервером достигает лимита десяти регистраций в час; затронутые сценарии проверяются отдельными запусками локального сервера без изменения рабочего лимита.
