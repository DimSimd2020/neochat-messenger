# Копирование в беседе

В личном чате, группе или канале откройте **⋯ → Копирование**. Копирование текста и файлов, пересылка и захват экрана настраиваются отдельно. По умолчанию все три действия разрешены. Запрет действует на уже полученные и новые сообщения. Для сообщений из защищённой беседы «В избранное» доступно, когда разрешены и копирование, и пересылка.

Каждый участник может запретить действие. Снять запрет может аккаунт, который его установил, с любого своего устройства. Другой участник видит «Запросить разрешение». На один запрет хранится один открытый запрос. Установивший запрет видит его в чате и в меню «Копирование». Если этот участник вышел из группы, запрет сохраняется до его возвращения и решения.

## Захват экрана

- Android защищает окно чата и его просмотрщики через `FLAG_SECURE`. Этот флаг также скрывает окно в системном списке недавних приложений. [Документация Android](https://developer.android.com/security/fraud-prevention/activities)
- Windows исключает окно NeoChat из поддерживаемого захвата через `SetWindowDisplayAffinity`. [Документация Microsoft](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowdisplayaffinity)
- iOS скрывает переписку при обнаружении записи или трансляции. Система сообщает приложению о разовом снимке после его создания. [Документация Apple](https://developer.apple.com/library/archive/qa/qa1970/_index.html)

Ограничения копирования и пересылки применяют обновлённые клиенты. Сервер проверяет права на изменение настроек, а содержимое сообщений остаётся зашифрованным. Офлайн-устройство использует последнюю полученную настройку.

## API и синхронизация

`PUT /v1/conversations/{id}/copy-protection` принимает текущую версию настроек и одно действие. Пример разрешения пересылки участником, который её запретил.

```json
{
  "rule": "forward",
  "action": "allow",
  "revision": 2
}
```

Правила `copy`, `forward` и `screenshot` изменяются действиями `block`, `allow` и `request`. Сервер проверяет активное устройство и членство в беседе. Устаревшая версия получает `409 copy_protection_changed`. Разрешение чужого запрета получает `403 copy_protection_owner_required`. Повторный запрет с текущей версией сохраняет первого автора. Повторный запрос с текущей версией сохраняет уже открытый запрос.

Настройка хранится отдельно от подписанного состояния группы. `GET /v1/conversations/{id}` возвращает `copy_protection` с версией и картой действующих запретов. Та же настройка приходит участникам через событие синхронизации `copy_protection`. Начальная синхронизация с `copy_protection=1` также возвращает снимок настроек доступных бесед. Сервер с миграцией `0018_copy_protection.sql` нужен перед распространением новых клиентов.
