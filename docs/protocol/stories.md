# Истории и серии в личных чатах

Android 0.7.6. Вход в истории находится на вкладке «Чаты». Редактор принимает одно фото или видео из файлов телефона, сохраняет видимую подпись, текст и его положение, штрихи кисти и эмодзи. Для фото доступны яркость, контраст и насыщенность. Видео можно обрезать до 60 секунд и убрать дорожку звука перед отправкой. Начальный файл ограничен 50 МиБ.

Автор выбирает аудиторию и срок показа 6, 12, 24 или 48 часов. «Все» включает доступных собеседников из существующих личных чатов. «Мои контакты» ограничивает эту аудиторию сохранёнными контактами. В обоих режимах можно добавить исключения. «Близкие друзья» использует сохранённый на устройстве список этого аккаунта, а «Выбранные пользователи» запоминает людей только для текущего черновика. Истории появляются в списке историй получателей и открываются в последовательном просмотрщике. Фото показывается шесть секунд, видео воспроизводится целиком. В просмотрщике есть пауза и ручная навигация.

## Конверт и срок показа

Публикация шифрует медиа штатным файловым форматом. В очередь атомарно записывается по одному пакету Signal для каждого выбранного личного чата. Один пакет доставляется актуальным устройствам участников беседы по существующему API отправки; собственные устройства сводят все копии к одному ID истории. HTTP-маршруты и серверные миграции для этого выпуска не требуются.

Во внутреннем зашифрованном конверте используется тип `story`. `file` содержит обычный `FileMeta`, в `text` лежит подпись до 240 символов, а `group` хранит данные истории.

```json
{
  "id": "69952d97-c894-46b8-a761-427418199f4f",
  "hours": 24,
  "style": {
    "text": "Хорошее утро",
    "text_y": 650,
    "color": 16777215,
    "lines": [[[250, 100], [275, 130]]],
    "stickers": [{"emoji": "✨", "x": 400, "y": 300}],
    "brightness": 10
  }
}
```

Положение и точки кисти задаются от 0 до 1000 относительно портретного холста. Получатель проверяет маршрут конверта, тип беседы, срок и размер перед записью. Старый клиент игнорирует новый тип. Подпись и история не попадают в переписку, её поиск, уведомления и резервную историю.

По истечении срока клиент прекращает показ и открытие истории, удаляет локальный файл и карточку. На сервере зашифрованный объект живёт по обычному сроку хранения вложений до 30 дней. Срок показа не отзывает ранее сделанные получателем копии.

Необязательные поля `text_color`, `text_align`, `text_font` и `text_background` задают цвет, выравнивание, начертание и подложку надписи. `brushes` хранит цвет и тип каждого штриха в том же порядке, что и точки в `lines`. Для старых записей сохраняются общий цвет, центрирование, прозрачный фон и тонкое перо.

## Огонёк

Серия считается по доступной локальной истории личной переписки. День по UTC засчитывается, если оба собеседника отправили хотя бы одно сообщение, принятое сервером. После трёх таких дней подряд огонёк и число дней видны в списке и в шапке чата. У собеседников есть весь текущий день, чтобы продлить серию.
