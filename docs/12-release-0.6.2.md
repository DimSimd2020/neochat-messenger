# NeoChat 0.6.2

Изменения подготовлены 20 октября 2026 года. Это отчёт о локальной реализации и проверках, не сообщение о публикации обновления.

## Поведение

- **iOS:** переписка получила собственный непрозрачный фон, фоновые градиенты обновляются без неявных анимаций Core Animation. Это устраняет условия, при которых предыдущий экран просвечивал во время навигации и появления меню. Подтверждение устранения артефакта на iPhone ещё требуется.
- **ПК:** меню сообщения — отдельная скруглённая поверхность с реакциями, значками действий, подсветкой, появлением и закрытием. Открывается по ПКМ и штатному клавиатурному вызову контекстного меню. ЛКМ выделяет текст, открывает фото/ссылку, выбирает вариант опроса или реакцию.
- **Набор текста:** точки у «печатает» меняются, пока действует подсказка от собеседника; сообщение прекращает подсказку, таймер удаляет истёкшее состояние. Reduced motion оставляет статичное многоточие.
- **Фото профиля:** выбор и удаление на трёх платформах; фото видно в профиле, списках и аватарах сообщений. Изображение подготавливается вне UI-потока. Для передачи фото между клиентами нужен обновлённый сервер с `0006_avatar.sql`.
- **Android:** ответ свайпом доступен из пустой части строки, как и нажатие. Вертикальная прокрутка, системные края и отмена жеста сохраняют своё поведение.
- **Вложения ПК:** Ctrl+V принимает изображение из буфера или несколько локальных файлов. Несколько фото можно выбрать одним действием; подготовка идёт последовательно вне UI-потока, в выбранном порядке. До 100 ожидающих вложений; прежний лимит файла 25 МиБ сохраняется. Фото отправляются отдельными сообщениями, общий протокол альбомов не добавлялся.
- **Выбор чатов:** Ctrl/Shift и «Выбрать чаты» на ПК; удержание и режим выбора на мобильных. Доступны архивирование/возврат, закрепление/открепление, очистка и удаление. Прежний лимит трёх закреплённых чатов сохраняется.
- **Очистка:** удаляет локальную историю, черновик, счётчик непрочитанных, связанные реакции/голоса/receipts и кэш вложений. Удаление чата дополнительно скрывает его из списков и снимает закрепление. Новое сообщение возвращает скрытый чат; из группы пользователь не выходит. Криптосессии и очередь отправки сохраняются, отправки продолжаются. Это указано в подтверждении. Действия не удаляют историю собеседников или других устройств.
- **Мобильный архив:** компактная строка с иконкой скрыта по умолчанию, раскрывается потягиванием списка вниз и уходит при возврате. Для screen reader предусмотрено отдельное действие раскрытия. Открытие самого архива сохраняет проверку код-пароля.

## Проверки

Windows 11, Qt 6.8.3, MSVC 2022; установленный Rust stable, Go и JDK 17. Android — существующий системный образ API 36.1, x86_64. Новые SDK и зависимости не устанавливались.

- `cargo test --offline --lib`: 15 проверок, включая локальную очистку, сохранность ciphertext/outbox и криптосессий, изоляцию другого чата и tombstone.
- `go test ./...`: пройдено. Проверка аватара включает удаление, корректный JPEG, неверный base64, посторонние данные, превышение размера и сторон, обрезанное изображение.
- `neochat_interactiontest`: 5 результатов Qt Test (три сценария, init/cleanup). Ctrl+V изображения/нескольких файлов/текста; ЛКМ без меню, ПКМ по сообщению и пустой части строки, копирование и Escape; сохранение фокуса поля ответа после закрытия меню.
- `scripts/uitest.sh`: 11 результатов Qt Test; реальный локальный сервер и второй клиент. Включены пачка фото через Ctrl+V, порядок и миниатюры, реакции, выделение текста, выбор чатов, массовый архив, подтверждение/отмена очистки и сохранение чужой истории.
- E2E ядра: 11 сценариев проверены. Первый общий прогон с live-режимом упёрся в лимит регистраций; оставшиеся сценарии проверены с новым локальным процессом сервера для каждого. Проверка обычного входа по паролю выполняется без `NEOCHAT_E2E_LIVE`; live-подсказки — с ним. Смена/удаление фото, локальная очистка и возвращение скрытого чата по новому сообщению проверены между двумя клиентами.
- Android: собраны Rust-библиотеки для `arm64-v8a` и `x86_64`, debug APK, тестовый APK и подписанный release APK. У release APK проверены подпись, `versionName=0.6.2`, `versionCode=12` и совпадение обеих встроенных библиотек ядра с финальной сборкой. `InteractionInstrumentation` на эмуляторе проверила свайпы вне пузыря в обе стороны, прокрутку, системный край и отмену жеста.
- Проверены снимки нового меню и сценариев Qt. Offscreen-платформа Qt не реализует прозрачность окон; визуальную плавность нельзя считать измеренной этим прогоном.

Команды сборки и запуска регрессий находятся в README соответствующих клиентов. Локальный PostgreSQL использовал отдельную базу `neochat_062_tests`; рабочий сервер не менялся.

## Локальные пакеты

В `dist/` подготовлены `NeoChat-0.6.2-x64.msi`, `NeoChat-0.6.2-android.apk` и `NeoChat-0.6.2-sha256.txt`. Версия MSI проверена через таблицу Property Windows Installer. Android подписан существующим ключом проекта; конфигурация подписи не менялась. Эти файлы не опубликованы на сервере обновлений.

## Перед выпуском iOS

На этой Windows-машине нет macOS/Xcode. Swift-изменения не прошли компиляцию и проверку на устройстве; IPA 0.6.2 здесь не собрана.

На macOS собрать по `apps/ios/README.md`, затем на iPhone:

1. Несколько раз открыть/закрыть чат, включая возврат с поднятой клавиатурой и отмену свайпа назад. Проверить отсутствие текста предыдущего экрана.
2. Открыть/закрыть меню сообщения, сведения, выбор эмодзи, фото и файлов; повторить быстрые действия и reduced motion.
3. Выбрать несколько чатов, закрепить/архивировать, отменить и подтвердить очистку. Проверить отсутствие старых сообщений после незавершённого запроса страницы.
4. Потянуть список вниз: архив появляется компактной строкой с иконкой. Закрыть его кнопкой и краевым свайпом; открыть архив и вернуться. Проверить код-пароль и VoiceOver.
5. Сменить/удалить фото, проверить его на другом клиенте; проверить профиль на небольшом экране и при увеличенном тексте.

## Обновление сервера

Для аватарок требуется серверная часть этой версии и применение встроенной миграции `0006_avatar.sql` штатной командой `migrate`. Публикация манифеста обновления, загрузка пакетов на рабочий сервер и изменение подписи приложений в эту локальную работу не входили.
