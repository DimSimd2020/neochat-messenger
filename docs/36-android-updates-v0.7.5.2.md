# Android 0.7.5.2: обновление через файловый менеджер

## Основной сценарий

1. NeoChat проверяет подписанный манифест обновлений и скачивает APK с проверкой размера и SHA-256.
2. Кнопка «Сохранить APK» открывает системный выбор документа через `ACTION_CREATE_DOCUMENT`. Пользователь выбирает папку (например, Downloads).
3. Файл копируется потоком вне UI; при успехе NeoChat предлагает открыть сохранённый APK в приложении «Файлы».
4. Установку инициирует файловый менеджер по действию пользователя. NeoChat не запрашивает `REQUEST_INSTALL_PACKAGES`, не вызывает PackageInstaller и не предлагает включить «Установку неизвестных приложений» для себя.

Обновлять поверх установленного NeoChat с прежней подписью; удаление приложения может удалить локальную историю. Облачная резервная копия не заменяет проверку миграции.

## Сравнительные сборки

Все три APK имеют один `applicationId=app.neochat`, одну версию и один ключ подписи. Они устанавливаются по очереди, а не рядом.

| Вариант | Разрешение REQUEST_INSTALL_PACKAGES | Alpha-манифест | Установка |
| --- | --- | --- | --- |
| Основной | Нет | Да, для разрешённых тестеров | Файловый менеджер |
| С разрешением | Да, только для A/B-теста | Да | **Тот же** файловый менеджер |
| Без alpha | Нет | **Не запрашивается вообще** | Файловый менеджер |

Для сравнительной сборки с разрешением: `./gradlew.bat assembleRelease -PNEOCHAT_TEST_INSTALL_PERMISSION=true`.
Для сборки без alpha: `./gradlew.bat assembleRelease -PNEOCHAT_DISABLE_ALPHA=true`.
По умолчанию оба флага выключены. В варианте без alpha доступны обычные stable/beta-каналы. Флаг передаётся в Rust для `check_update` и `download_update`, чтобы отключение не зависело от UI.

**Ограничения:** системный диалог сохранения может выглядеть по-разному на разных Android; физические устройства и реакцию Play Protect нужно проверить отдельно. APK без разрешения больше не может автоматически установить собственное обновление. Альфа 0.7.5 на сервере остаётся без изменений до отдельного решения о публикации.

## Решение для 0.7.5.3 (локальная проверка)

По результатам проверки Play Protect основной Android release **не содержит** `REQUEST_INSTALL_PACKAGES`: диагностический manifest overlay выключен по умолчанию. Alpha-канал обновлений включён для разрешённых тестеров; отдельная сборка с `-PNEOCHAT_DISABLE_ALPHA=true` его отключает. Собственные обновления NeoChat сохраняются через `ACTION_CREATE_DOCUMENT` и устанавливаются из файлового менеджера. Для сравнительной сборки с разрешением используйте `-PNEOCHAT_TEST_INSTALL_PERMISSION=true` (это не меняет способ установки обновлений).

Исправления виброотклика: Android 13+ использует `VibratorManager` с `USAGE_TOUCH` даже до прикрепления View к окну, слабое `EFFECT_TICK` для выбора заменено на `EFFECT_CLICK`, камера и QR используют тот же механизм. В «Оформление» есть пункт «Проверить виброотклик» с `EFFECT_HEAVY_CLICK`; успешная отправка команды не гарантирует реальную вибрацию, если Android отключил тактильную отдачу. Реальный Pixel 8 нужно проверить отдельно.

Релиз 0.7.5.3 не опубликован в stable или alpha. Готовый тестовый APK лежит в папке Downloads ПК.
