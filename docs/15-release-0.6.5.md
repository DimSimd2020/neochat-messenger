# Правки 0.6.5

Ветка `fixes-0.6.4`, выпуск `v0.6.5-preview` (предварительный): версии 0.6.5 (Android `versionCode=15`, iOS сборка 15). Изменение своих сообщений (служебное E2EE-сообщение `edit`), окно отправки вложений с подписью на Windows, листание и увеличение фото на телефонах, исправления краша Android и зелёной плашки iOS. Автообновление публикуется для каждого выпуска, в том числе `-preview`. Заметки «Что нового» — в `core/src/whatsnew.rs`.
