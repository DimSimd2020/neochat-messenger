# Правки 0.6.5.1

Ветка `fixes-0.6.4`, выпуск `v0.6.5.1-preview` (предварительный): версии 0.6.5.1 (Android `versionCode=16`, iOS сборка 16). MSI с четвёртым числом заменяет 0.6.5 благодаря `AllowSameVersionUpgrades`. Окно отправки с подписью теперь есть и на телефонах, а картинка из буфера обмена на всех трёх платформах сначала открывается в нём, а не уходит сразу. Зум фото на Android переписан на экранные координаты. Автообновление публикуется для каждого выпуска.
