## Выпуск обновления

Текущая стабильная сборка — 0.6.9.2. Её получают клиенты без переключателя и с выбором stable. Выпуск 0.6.7: [профили, упоминания, архив, сборки и проверки](docs/18-release-0.6.7.md). Предыдущая стабильная: [0.6.5.2](docs/17-release-0.6.5.2.md).

Собрать `dist/NeoChat-<версия>-x64.msi`, `-android.apk` и `-ios-unsigned.ipa`. В `dist/` лежат только эти три файла на каждую версию: без логов, снимков, каталогов веток и промежуточных копий. Затем:

- APK подписывается sideload-ключом из `apps/android/keystore` (сборка без `NEOCHAT_SIGNING`), как все опубликованные версии. Иначе обновление не встанет поверх.
- Заметки окна «Что нового» хранятся в ядре (`core/src/whatsnew.rs`); новую версию нужно добавить туда.

```sh
python infra/publish-update.py 0.6.9.2 "Что нового" stable
```

Третий аргумент — канал, `stable` по умолчанию. `beta` не заменяет стабильный манифест. Скрипт подписывает манифест офлайн-ключом (`E:/dev/keys/update-signing.key`, в репозиторий не попадает) и кладёт файлы на сервер. Приложения 0.4.0 и новее находят обновление своего канала сами: Windows ставит и перезапускается, Android открывает установщик, iOS даёт ссылку на IPA для Scarlet. Переключатель канала есть с 0.6.7.2.
