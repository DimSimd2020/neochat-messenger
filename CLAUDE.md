# NeoChat: начало работы

Правила для всего проекта находятся в [AGENTS.md](AGENTS.md); прочитай их перед изменениями. Они действуют и при работе через Claude.

Клиенты и сервер реализованы и выпускаются; актуальная стадия — в [AGENTS.md](AGENTS.md). Начни с [README](README.md). Макеты дизайна: [веб](docs/design/preview.html), [Android](docs/design/android.html), [токены](docs/design/tokens.json).

Инструменты установлены: собирай и проверяй настоящей сборкой (`apps/android/gradlew` на JDK 17, Android SDK и NDK, cargo для `core/`, Python для `infra/`), скачивание gradle-дистрибутива и зависимостей Maven при первом прогоне — норма, а не установка, требующая разрешения. Развёртывание сервисов и любые изменения на сервере — только по запросу пользователя.

Сохраняй согласованный дизайн, плавные переходы и reduced motion. Приложения и сервер реализованы и релизятся, но макеты `docs/design/` реализацией не являются: обязательное E2EE нельзя подменять демонстрацией из HTML.
