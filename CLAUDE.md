# NeoChat: начало работы

Правила для всего проекта находятся в [AGENTS.md](AGENTS.md); прочитай их перед изменениями. Они действуют и при работе через Claude.

Текущая стадия — проектирование. Начни с [README](README.md) и [памятки передачи](docs/11-motion-and-handoff.md). Актуальный дизайн — эскиз 10: [веб](docs/design/preview.html), [Android](docs/design/android.html), [спецификация](docs/05-interface.md), [токены](docs/design/tokens.json).

Пользователь отменил установку инструментов. Передача проекта не разрешает установку SDK/зависимостей, развёртывание или изменение сервера. Дождись конкретной задачи пользователя; при начале реализации следуй этапам из [плана](docs/06-roadmap.md).

Сохраняй согласованный дизайн, плавные переходы и reduced motion. Приложения, сервер и шифрование ещё не реализованы; обязательное E2EE нельзя подменять демонстрацией из HTML.
